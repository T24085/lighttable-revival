# Original 0.8.1 feature recovery

Reference installation: the official 0.8.1 Windows reference installation, inspected on 2026-10-05. Its application manifest identifies version 0.8.1. The current revival remains based on the original upstream develop source; the older installation is a reference for bundled plugins, not a replacement for the current core. No files in that installation were changed.

The user chose to bring missing features into the current build. The comparison below distinguishes shipped plugin code from working, tested runtime integration.

The current build also adds a local Ollama project assistant: Chat / Activity docking, project scaffolding, canonical file edits and undo, commands, actual native preview inspection and paused recovery. This is a new capability alongside legacy feature recovery. See [ASSISTANT.md](ASSISTANT.md); inline autocomplete, MCP and cooperating model agents remain later work.

Current memory allowance: local execution, npm servers/installers, browser live views, Python/ClojureScript and the IPython client helper use 1 GiB process-family limits. Local Clojure uses a 1 GiB Java heap with a 2 GiB total process-family allowance. Restart to apply. Prior verification paragraphs retain their original memory values.

Follow-up compatibility inspection on 2026-10-05 found that the old installation used `Debugger.setScriptSource` for live replacement. The current Electron 44.5.1 / Chromium 152.0.7977.130 returns `setScriptSource functionality no longer available`, including for a dry run against an actual project script. `.revival/state-preservation-probe-result.json` records the native three-check compatibility probe, verified 192 MiB quota, preserved DOM/model/timer on rejection, restored disposable test state and zero remaining processes/jobs/helpers. This confirmed an unavailable legacy mechanism. The subsequent implementation uses stable function wrappers and live constant cells, stylesheet edits and matched DOM updates; it does not depend on that removed API. The [current protocol reference](https://chromedevtools.github.io/devtools-protocol/tot/Debugger/#method-setScriptSource) marks the method deprecated. Native tests verify preserved object, callback, counter, renderer, canvas and typed input identity, and link errors to the exact patched source.
